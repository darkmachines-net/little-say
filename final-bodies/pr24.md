## Summary

Families currently keep boards and saved media only on each device, so reinstalling or moving devices can lose their library. This adds optional Firebase sign-in and consent-based backup to the selected server, while preserving guest use, offline playback, and local boards after sign-out.

Backups validate media with SHA-256, retain conflicting edits, enforce per-account quotas, and retry interrupted deletion. Browser sessions use HttpOnly cookies; native credentials use SecureStore. The accounts migration follows the existing foundation and grant migrations without replacing them.
