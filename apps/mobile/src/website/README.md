# Public web experience

`Entry.web.tsx` loads the welcome page at `/` and the read-only starter trial at `/app/try` (including its trailing-slash form). The welcome's **Try Little Say on the web** link opens the trial. **Log in** and **Create account** open `/app/account/login` and `/app/account/register` directly. `/app` retains the normal account flow; installed web apps still launch there. Native `Entry.tsx` does not import this module.

Ordinary trial-link clicks navigate within the loaded page, and Back/Forward restores the public route without restarting JavaScript. The link retains its real URL for modified clicks and new tabs. Hover or keyboard focus preloads the trial module without mounting services. A full-screen indeterminate spinner stays centered while either the trial or account app code loads, with an accessible loading label and no visible loading text. The starter catalog itself is synchronous bundled data; development builds may spend additional time compiling the lazy module on first access.

`TryBoards.web.tsx` uses the shared [starter catalog](../../../../packages/core/README.md) and the app's `BoardCard` and `PlayBoard` controls. Guests can play all three boards, tap or swipe cards, lock the player, and return to the list. `useTrialSpeech.web.ts` uses the ordinary `SpeechLibrary` with transient state and credential-free cache lookups. [Server speech seeding](../../../server/seeds/speech/README.md) supplies the intended AI voice through the same API and cache as signed-in tiles, without an OpenAI key at playback time. WAVs load on tap; missing cache entries, failed downloads, or decoding failures fall back to device speech. Rendering does not wait for audio. The trial starts no account, sync, translation, or AI-generation services, and does not read or write saved libraries, preferences, or media. Its board selection is discarded on reload.

Public components and their shared dependencies use narrow core module imports and `lucide-react-native/icons/<name>` imports. Avoid runtime imports from either full barrel: Metro can otherwise promote the emoji catalog, every icon, and editor dependencies into the shared initial chunk. The web request-auth adapter uses cookie/CSRF helpers independently of the Firebase SDK. Browser coverage limits cold public JavaScript to 1.5 MB before compression and checks that the account app chunk stays unloaded.

New board, Edit, Favorite, and More open the same dismissible account prompt before any mutation controls appear. **Create a free account** opens `/app/account/register`; **Sign in** opens `/app/account/login`. Dismissing the prompt leaves the trial unchanged. Guest state is never copied into an account.

`landing.css` belongs only to the welcome page. Reuse the [shared UI conventions](../ui/README.md) for the trial. Browser coverage in `tests/web/trial.spec.ts` checks seeded speech through normal API routes, fallback, gates, navigation, layout, and storage isolation; `landing.spec.ts` owns welcome, account links, bundle budget, and installed-app routing.
